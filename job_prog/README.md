# 💼 Job Application Tracker (ระบบติดตามการสมัครงาน/ฝึกงาน - Desktop GUI)

โปรแกรมติดตามการสมัครงานและฝึกงานแบบ **Desktop GUI (หน้าต่างโปรแกรมบนคอมพิวเตอร์ ไม่ใช่เว็บไซต์)** 
พัฒนาด้วยภาษา **Python (Tkinter + ttk)** และ **SQLite** สำหรับจัดเก็บฐานข้อมูลแบบ Standalone รันจบในไฟล์เดียว

---

## 📌 คุณสมบัติเด่น (Features)

1. **ระบบบันทึกและจัดการข้อมูล (CRUD เต็มรูปแบบ)**:
   - **เพิ่มข้อมูล (Create)**: ฟอร์มกรอกชื่อบริษัท, ตำแหน่งงาน, วันที่สมัคร (YYYY-MM-DD), ช่องทางที่สมัคร (LinkedIn, เว็บบริษัท, Email, ฯลฯ), ลิงก์ประกาศงาน, สถานะเริ่มต้น และหมายเหตุ
   - **ดูข้อมูล (Read)**: แสดงผลในตาราง Treeview พร้อมระบบค้นหา (Search) และตัวกรองตามสถานะ/ช่องทาง
   - **แก้ไขข้อมูล (Update)**: หน้าต่าง Popup Dialog ให้แก้ไขข้อมูลทุกฟิลด์ได้ทันที (หรือดับเบิ้ลคลิกแถวในตาราง)
   - **ลบข้อมูล (Delete)**: ปุ่มลบรายการพร้อมกล่องยืนยันป้องกันการเผลอกดลบ
   - **เปิดลิงก์ประกาศงาน**: กดปุ่มเปิดเว็บเบราว์เซอร์ไปยัง URL ประกาศงานโดยตรง

2. **ระบบแจ้งเตือนอัจฉริยะ (Smart Notification & Alert)**:
   - คำนวณระยะเวลาจาก **"วันที่สมัคร"** จนถึง **"วันปัจจุบัน"** อัตโนมัติ
   - รายการที่สถานะเป็น **"กำลังรอผล"**:
     - 🚨 **วิกฤต (> 30 วัน)**: ไฮไลต์แถบสีแดงในตาราง และแสดงการ์ดแจ้งเตือนสีแดง (บริษัทอาจเงียบหาย)
     - ⚠️ **เตือนติดตาม (> 14 วัน)**: ไฮไลต์แถบสีเหลือง/ส้มในตาราง และแสดงการ์ดแจ้งเตือนสีส้ม (ควรรีบส่งอีเมลถามความคืบหน้า)
   - มีแท็บ **"🔔 แจ้งเตือนรอนาน"** แสดงรายการและป้ายจำนวนที่ค้างรอผลชัดเจน

3. **การจัดการด่วน (Quick Actions)**:
   - 🔄 **สมัครใหม่ / Follow-up**: รีเซ็ตวันที่สมัครเป็นวันปัจจุบัน และบันทึกประวัติลงในหมายเหตุให้อัตโนมัติ
   - 🎯 **นัดสัมภาษณ์** / 🎉 **ได้งานแล้ว**: อัปเดตสถานะทันทีในคลิกเดียวโดยไม่ต้องเปิดฟอร์มแก้ไข
   - 🗑️ **ลบออก / ปิดเคส**: ลบรายการที่บริษัทไม่ตอบรับ

4. **Dashboard สรุปสถิติ & กราฟ (สำหรับพรีเซนต์อาจารย์)**:
   - การ์ดสรุปตัวเลข (KPI Metrics): สมัครทั้งหมด, กำลังรอผล, สัมภาษณ์, ได้งานแล้ว, ปฏิเสธ, อัตราความสำเร็จ (%)
   - **Donut Chart (กราฟวงกลม)**: วาดด้วย Tkinter Canvas แสดงสัดส่วนสถานะการสมัครงานพร้อมคำอธิบายสี (Legend)
   - **Bar Chart (กราฟแท่ง)**: วาดด้วย Tkinter Canvas แสดงจำนวนการสมัครแยกตามช่องทาง
   - **🎲 ปุ่มเติมข้อมูลตัวอย่าง (Demo Data)**: กดปุ่มเดียวสร้างข้อมูลจำลอง 7 รายการ ครบทุกเคสสำหรับทดสอบพรีเซนต์ได้ทันที

5. **Export ข้อมูลเป็น Excel / CSV**:
   - บันทึกไฟล์ CSV ด้วยการเข้ารหัส `utf-8-sig` (เปิดใน Microsoft Excel บน Windows ภาษาไทยไม่เป็นภาษาต่างดาว)

## 🚀 วิธีเปิดใช้งานโปรแกรม

โปรแกรมนี้พัฒนาด้วย **Python Standard Library 100%** (ไม่ต้องติดตั้งโมดูลใดๆ เพิ่มเติม)

**วิธีที่ 1 (สะดวกที่สุด):**
ดับเบิ้ลคลิกไฟล์ `run.bat` ในโฟลเดอร์นี้เพื่อเปิดโปรแกรมได้ทันที

**วิธีที่ 2 (ผ่าน Command Line):**
เปิด Terminal / PowerShell ในโฟลเดอร์นี้ แล้วรันคำสั่ง:
```bash
python app.py
```
หน้าต่างโปรแกรม Desktop GUI จะเปิดขึ้นมาตรงกลางหน้าจอทันที!

## 📂 โครงสร้างไฟล์
- `app.py` : ตัวโปรแกรม Desktop GUI รันจบในไฟล์เดียว
- `fonts/` : โฟลเดอร์บรรจุฟอนต์ Prompt (Regular, Medium, Bold) โหลดเข้าโปรแกรมอัตโนมัติ
- `run.bat` : ชอร์ตคัตสำหรับดับเบิ้ลคลิกรันบน Windows
- `job_tracker.db` : ไฟล์ฐานข้อมูล SQLite (สร้างอัตโนมัติในเครื่อง)
- `README.md` : เอกสารคู่มือและการอธิบายระบบ
- `requirements.txt` : คำอธิบายเกี่ยวกับโมดูลมาตรฐาน
